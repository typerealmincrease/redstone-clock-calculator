## 📖 About

Redstone Clock Calculator computes the pulse frequency, period, and duty cycle of any standard redstone clock design and helps you tune the timing for farm automation.

---

## ✨ Features
<a name="features"></a>

- **All Clock Types** — torch, comparator, observer, hopper, dropper.
- **Frequency Display** — pulses per second and per minute.
- **Duty Cycle** — on-time vs. off-time percentage.
- **TPS Scaling** — adjusts for sub-20 server TPS.
- **Farm Timing Guide** — recommended clock for common farms.
- **Export** — save design spec to text file.
